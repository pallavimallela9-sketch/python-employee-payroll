# Employee Payroll Management System

This Python program calculates an employee's payroll using basic salary, HRA, DA, and other deductions. It also displays the gross salary, net salary, and salary category.

## Features

* Accepts employee details
* Calculates HRA based on percentage
* Calculates DA based on percentage
* Calculates gross salary
* Calculates deductions
* Calculates net salary
* Displays salary category

## Technology Used

* Python

## Concepts Used

* Variables
* User input
* Arithmetic operations
* Conditional statements
* Percentage calculation
* Formatted output

## Salary Calculation

HRA = Basic Salary × HRA Percentage / 100

DA = Basic Salary × DA Percentage / 100

Gross Salary = Basic Salary + HRA + DA

Net Salary = Gross Salary - Deductions
